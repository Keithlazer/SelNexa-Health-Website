# SelNexa Health website icons

Prepared for Keith by Claude on 14 November 2026. These 74 icons replace the Canva icon list: Canva's library cannot be reached through the Canva connection, so the set comes from Phosphor Icons 2.1.1 (regular weight, MIT licence, see LICENSE-phosphor.txt). One style, one stroke weight throughout.

## Instructions for Claude Code

- `selnexa-icons-sprite.svg` holds all 74 icons as `<symbol>` elements. Each symbol id is the name in the tables below, and each uses `fill="currentColor"`, so colour comes from CSS.
- Merge these symbols into `assets/icons/sprite.svg` and reference them with `<svg><use href="/assets/icons/sprite.svg#home-iterate-fast"></use></svg>`.
- This set replaces the Phosphor mapping in Phase 2 of the UI refresh brief for every slot listed here. Ignore the brief's Phase 6 line about Canva icons. Use the brief's Phosphor icons only for interface controls (menu, close, arrows, plus and minus) and for any slot not listed.
- Style per the brief's Phase 2: 24 to 28 px icon in a 48 px rounded square with a pale gold tint, navy icon, `aria-hidden="true"` when decorative.
- Keep LICENSE-phosphor.txt in `assets/icons/`.
- Keep the official UN SDG icons as they are. Share buttons for LinkedIn, X and WhatsApp use each company's official logo.
